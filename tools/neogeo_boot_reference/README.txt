Original BIOS execution capture scripts retain the investigation workspace paths. They require Unicorn M68000, original neo-epo.bin/sfix.sfix/000-lo.lo and Metal Slug C-ROMs. The portable build tool is tools/build_neogeo_boot.py and uses the included art/neogeo-boot/bios-replay.npz. Capture is an offline BIOS execution harness, not a full Neo Geo emulator. Sound is the existing original sound-driver command2 recording (6000 Hz IMA).
