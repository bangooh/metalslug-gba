# Metal Slug GBA 0.9.0 — 원본 파일 기반 로컬 빌더

Bangoo의 비공식 GBA 팬 포트입니다. 사용자가 준비한 원본 `mslug.zip`과 Neo Geo BIOS `neogeo.zip`에서 필요한 데이터를 추출·변환하고, 편집한 그래픽 변경분을 적용하여 GBA ROM을 만듭니다.

원본 ROM·BIOS·완성된 원작 그래픽·음원·GBA ROM은 이 저장소에 포함하지 않습니다. 과거 개발 이력이 없는 별도 공개 저장소이며, 복원된 파일은 사용자 컴퓨터에서만 생성됩니다.

## 필요한 원본 파일

**`mslug.zip`(네오지오 메탈슬러그 1)**과 **`neogeo.zip`(네오지오 BIOS)**을 준비하고, 각각의 로컬 경로를 `--rom`과 `--bios`에 지정하세요. 두 파일은 저장소에 포함하지 않습니다.

ZIP 크기·압축률·파일 순서·날짜는 달라도 됩니다. ZIP 전체 해시 대신 **압축 내부 파일**로 호환성을 확인합니다. 아래 CRC32는 파일 식별용이며, 빌더는 [assets/input-hashes.json](assets/input-hashes.json)에 기록된 정확한 파일명·크기·**SHA-256**을 검증합니다.

### 게임 ZIP: `mslug.zip`

아래 9개는 표준 Metal Slug - Super Vehicle-001 게임 ROM 세트와 일치합니다.

| ZIP 내부 파일명 | 크기(바이트) | CRC32 |
|---|---:|---|
| `201-p1.bin` | 2,097,152 | `08d8daa5` |
| `201-m1.bin` | 131,072 | `c28b3253` |
| `201-v1.bin` | 4,194,304 | `23d22ed1` |
| `201-v2.bin` | 4,194,304 | `472cf9db` |
| `201-s1.bin` | 131,072 | `2f55958d` |
| `201-c1.bin` | 4,194,304 | `72813676` |
| `201-c2.bin` | 4,194,304 | `96f62574` |
| `201-c3.bin` | 4,194,304 | `5121456a` |
| `201-c4.bin` | 4,194,304 | `f4ad59a3` |

현재 저장소 빌더는 위의 `.bin` 파일명과 대소문자를 요구합니다. 내용이 일치하는 파일이 `201-p1.p1`, `201-c1.c1` 같은 MAME 파일명이라면 각각 `201-p1.bin`, `201-c1.bin`으로 이름을 바꾸어 재압축하세요. 이름을 바꾸어도 내부 데이터와 요구 해시는 달라지지 않습니다. 필요한 각 파일명은 ZIP에 정확히 한 번만 있어야 합니다.

### BIOS ZIP: `neogeo.zip`

| ZIP 내부 파일명 | 크기(바이트) | CRC32 |
|---|---:|---|
| `sfix.sfix` | 131,072 | `c2ea0cfd` |
| `000-lo.lo` | 131,072 | `5a86cff2` |
| `neo-epo.bin` | 131,072 | `d27a71f1` |

BIOS 파일은 하위 폴더 없이 ZIP 최상위에 넣으세요. 다른 지역 BIOS나 UniBIOS만 들어 있는 ZIP으로는 부족하며, 위 목록 및 매니페스트의 SHA-256과 일치하는 파일이 필요합니다. 이외의 추가 파일은 허용합니다.

## 빌드

Linux, Python 3.12, Git, 호스트 GCC/G++, GNU Arm Embedded GCC 14.2.Rel1 환경에서 검증했습니다.

```sh
python3 -m venv .venv
. .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 build_rom.py --rom /경로/mslug.zip --bios /경로/neogeo.zip --cc /경로/arm-none-eabi-gcc
```

원본 ZIP 내부 파일의 이름·크기·SHA-256은 [입력 목록](assets/input-hashes.json)을 확인하세요. 저작권 자료의 다운로드 링크는 제공하지 않습니다. 최초 실행 시 고정된 버전의 upstream 소스를 내려받습니다. 수 GB의 여유 공간이 필요합니다.

결과는 `dist/metal-slug-gba-native-v0.9.0.gba`에 생성됩니다. 릴리즈 버전은 **0.9.0**입니다. 0.9.0 빌드 및 에셋 복원 검증을 완료했습니다. 링크 플레이에서는 두 기기 모두 같은 0.9.0 빌드를 사용하세요. 용량은 33,518,376바이트이며 SHA-256은 `51459b145f87e263ea4b77af3daf9e1bc41aaad7d77c6fd349fb554c98da4f9c`입니다. 이번 작업에서 별도의 실기 플레이 검증을 수행한 것은 아닙니다.

## 권리 표기

원작 게임과 캐릭터·그래픽·음악의 권리는 SNK 등을 포함한 해당 권리자에게 있습니다. GBA는 Nintendo의 상표이며 본 프로젝트는 비공식입니다. 직접 만든 작업과 원작 기반 수정 작업을 구별하며, 원본 파일을 요구하는 방식 자체가 모든 저작권 문제의 해소를 보장하지는 않습니다.

원작 데이터를 포함하지 않는 배포 구조로 변경했으며, 수정한 캐릭터·HUD·폰트는 원본 추출 결과에 변경 픽셀을 적용하여 보존합니다. 원작 비교 이미지와 완성된 편집 파일도 로컬에서만 복원합니다. [권리 고지](NOTICE.md), [제3자 고지](THIRD_PARTY_NOTICES.md), [자산 구성](ASSET_PROVENANCE.md), [상세 빌드 안내](REBUILD.md)를 참고하세요.

생성된 `art/`, `generated/`, `build/`, `dist/`와 ROM·BIOS를 공개 저장소·이슈·릴리스에 업로드하지 마세요.
